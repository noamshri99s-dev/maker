# Maker — דף נחיתה ליוצרים

דף נחיתה בעברית (RTL) עבור Maker: רשת של יוצרים שמצלמים את עצמם ומקדמים מוצרים של עסקים משלמים.
בנוי ב-React 18 + Vite, בלי ספריות UI חיצוניות.

## הרצה מקומית

```bash
npm install
npm run dev
```

הדף יעלה על http://localhost:5173

```bash
npm run build     # בנייה לפרודקשן (תיקיית dist)
npm run preview   # תצוגה מקדימה של הבילד
```

## מה צריך לעדכן (`src/content.js`)

כל הטקסטים, המספרים והקישורים יושבים בקובץ אחד. מה שמסומן ב-`TODO` הוא מה שנשאר פתוח:

| שדה | מה זה |
| --- | --- |
| `site.ctaHref` | לאן ה-CTA מוביל (וואטסאפ / גוגל פורמס / mailto) |
| `numbers.payPerUnit` | כמה משלמים על כל 1,000 צפיות |
| `numbers.bonusAmount` | גובה הבונוס |
| `numbers.bonusViews` | יעד הצפיות שמפעיל בונוס (ברירת מחדל: 50K) |
| `numbers.windowDays` | חלון הזמן לספירת הצפיות |

הטופס ב-`src/components/FinalCta.jsx` מציג כרגע אישור ופותח את `site.ctaHref`.
כדי לחבר אותו לטופס אמיתי — יש `TODO` בפונקציית ה-`submit`.

## מבנה הדף

1. **Hero** — כותרת על הרווח מהרשתות, זווית ה"ביחד", CTA
2. **מה זה Maker** — רשת יוצרים שמצלמים את עצמם
3. **בלי צורך בעוקבים** — כמות הפוסטרים היא המוצר
4. **איך זה עובד** — תרשים פּוּל ב-SVG + 7 שלבים
5. **כמה מרוויחים** — פּוּל, צפיות, ניקוד, בונוסים
6. **קהילה** — איור רשת היוצרים ב-SVG
7. **CTA לסיום** — טופס הצטרפות

## עיצוב

- כתום `#ff6a1a` על רקע קרם חם `#fbf7f0`
